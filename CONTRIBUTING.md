# Contributing to this project

Thanks for wanting to help out! Since I'm the main developer, keeping things organized helps me a lot.

Here is how you can contribute:

### 1. Reporting bugs or Suggesting features
* Check the **Issues** tab first to make sure someone else hasn't already reported it.
* If it's new, open a new Issue and describe the problem clearly.

### 2. Fixing bugs or Adding code
1. Fork this repository
2. Test your code. Make sure that the tool still works safely and reliably.
3. Open a **Pull Request** and briefly explain what you changed.

### 3. Code style
* Keep your code clean.
* Don't add unnecessary dependencies.

Please note that all contributors are expected to follow our [Code of Conduct](Code_Of_Conduct.md) to keep things friendly.
