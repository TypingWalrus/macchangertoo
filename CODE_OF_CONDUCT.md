# Code of Conduct

Hello, as of now, this is a one-person project but everyone is welcome to contribute :). Anyways, everyone is welcome to use this tool and open issues if something breaks.

Since this tool deals with MAC addresses, please use it responsibly and legally.

### Ground Rules
* **Be nice**: No insults or personal attacks.
* **Be helpful**: If you find a bug, explain it clearly so I could fix it.
* **Keep it clean**: No spam or annoying behavior.

### Enforcement
I run this repo by myself. If anyone is rude, I will just block you. Let's focus on the code.

### Contact
If you need to report something, open an issue.
